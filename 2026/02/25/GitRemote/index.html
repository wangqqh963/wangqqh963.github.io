2026/2/25 Technology Git Github

利用github服务在不同设备同步自己的更新内容

  • 起因：

    我的hexo是在2个设备都有的部署的用于备份说是，但是手动复制过去太麻烦了。突然发现忘记了git是可以同步内容的好帮手来着。所以就写了这篇git的remote到github用来同步内容的文章，这算不算把GitHub当网盘来用（

git使用基本教程：

如果您想了解更多请访问 Git教程 | 菜鸟教程

  • 在不使用远程服务的情况下的几步，

    1. 初始化仓库

      在目录下使用git init初始化本目录为一个仓库

      git init

      可有可无，把默认的分支名字改成了main

      git branch -M main

    2. 添加文件

      初始化仓库后使用git add <filename>添加任务文件

      git add ./

    3. 提交版本

      现在我们已经添加了这些文件，我们希望它们能够真正被保存在Git仓库。

      git commit -m "a commit"

  • 创建GitHub仓库

    在接入自己的仓库之前需要先创建自己的GitHub仓库，在GitHub创建一个就是了，如果不会用GitHub可以参考：

    git仓库创建连接

  • 接入自己的GitHub仓库

    1. 添加远程库

      要添加一个新的远程仓库，可以指定一个简单的名字，以便将来引用,命令格式如下：

      git remote add [shortname] [url]

      用起来是这样的

      git remote add origin git@github.com:you/gitrepository.git

    2. 推送仓库内容

      git push -u origin main

    3. 拉取仓库内容

      git pull origin main
